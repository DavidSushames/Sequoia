## Description
An organic [[-Exotic Materials|exotic material]].
Fertiliser made from the sap of a tree with the same name. It makes plants grow really well and quickly but it also makes them slightly poisonous. Not recommended for use on crops intended for consumption, use instead on cotton, flax, etc.

Makes your tummy hurt. You might throw up if you consume a meal solely of veggies grown with this stuff. Maybe long term consequences but no one has wanted to deal with sore tummies long enough to get really really sick from it.

Probably some culture out there who had to subsist on this stuff and eventually built up a resistance.
